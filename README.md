# Dark Visualsz — Bootstrap Creative Agency Homepage

A unique responsive Dark Visualsz homepage inspired by the *layout/energy* of the supplied sample site, but not copied.

## Stack
- HTML5
- Bootstrap 5.3.3
- Custom CSS
- Vanilla JavaScript

## Key features
- Dark Visualsz logo is used only as branding in the header/footer — never as a background.
- Hero background automatically rotates every 5 seconds.
- Background moods include digital marketing, photography and creative production imagery.
- Simple custom pointer: red dot + ring, with no oversized custom cursor artwork.
- Responsive Bootstrap navigation and layout.
- Custom scroll reveals, ticker, parallax-style hover, CTA interactions and progress bar.

## Images
The rotating hero and project backgrounds use remote Unsplash image URLs. For production, download properly licensed images and put them in `assets/images/`, then replace the URLs in `index.html` / `styles.css`.

## Run
Open `index.html`, or use VS Code Live Server for the best local development experience.
